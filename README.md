# ⚽ PRODE Mundial 2026 v2

Sistema de pronósticos para el Mundial de Fútbol 2026.

## Características

- 🏆 Pronósticos de los 64 partidos del Mundial
- 📊 Tabla de posiciones con puntaje en tiempo real
- 📄 Generación y lectura de PDF con pronósticos
- 👥 Sistema multiusuario con Firebase Firestore
- 🔐 Panel de administración con autenticación
- 📱 Diseño responsive

## Tecnologías

- HTML5 / CSS3 / JavaScript (vanilla)
- Firebase Firestore (base de datos)
- Firebase Auth (autenticación admin)
- jsPDF (generación de PDFs)
- pdf.js (lectura de PDFs)

## Deploy

El sitio se puede deployar con GitHub Pages apuntando a la rama main.
